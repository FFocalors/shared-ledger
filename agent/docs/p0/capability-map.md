## 共同授权与版本结论

- 公开业务 RPC 普遍撤销 PUBLIC/anon execute 并授予 authenticated；敏感写入口通过 security-invoker wrapper 进入 private helper，由 helper 读取 auth.uid() 并再次检查活动成员、Creator、记录者、claim/代理、活动状态与关联 Participant。表直接写权限被撤销或由触发器锁住，不能只看 EXECUTE 授权就推导 actor 可改任意账本。
- 数据库 CAS 与版本字段按操作区分。Settlement/Prepayment/Final v2 使用 Activity financial_version + request_id + Transfer request_payload/request_result；Expense 财务创建/修改没有客户端 expected_version/request_id，但事务行锁、版本递增和 financial lock trigger 仍存在；presentation 有可选 Expense expected_version。
- 后端业务 preview 目前只覆盖 settlement/prepayment/final 等明确入口，并非所有写的统一 preview。Agent 目标的 trusted preview、用户确认、固定命令、跨请求 durable execution key、通用回执和未知结果恢复都尚未实现。
- 核对以迁移链中的最新替换定义为准。API 合同 draft 中 owner/admin、update_expense_with_allocations、所有 update 都 expected_version CAS、dispute 改 transfer status 等说法与实际 RPC 不符；漂移细项见 [工程审计](engineering-audit.md)。
