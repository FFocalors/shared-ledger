# Experiment B Paired Grounding Diagnostic

Final status: `EXPERIMENT_B_GROUNDING_SIGNAL_WEAK`.

This diagnostic compares 48 paired prompts from the current authoritative-grounding set: 39 static policy receipts across seven Scenario states and nine local-backend receipts across two states. It uses the frozen v0.1 model checkpoint-33 at `D:\AI\runs\shared-ledger\training_runs\qlora-v0.1\20260930-143013\train\checkpoints\checkpoint-33`, with base model `D:\AI\models\Qwen3.5-4B`. No training or tuning occurred. The 60 blocker samples were excluded and left blocked.

For each pair, A is the original v0.1 model-visible input and B adds the complete authoritative receipt only in `server_context.runtime_policy.tool_results`. The SYSTEM_INSTRUCTION behavior text, conversation/history, user text, other context, enabled tools, verified-result whitelist, generation setup, and expected outputs are identical. The serializer places runtime context JSON inside the serialized system field, so that field changes only in the `tool_results` receipt subtree; conversation and user fields are byte-for-byte identical. The 48 serialized pair records and generation traces are in `paired_inputs.json` and `generation_records.jsonl`. The model was loaded once and generated sequentially with `qwen3_5_nothink`, no thinking, NF4, `max_new_tokens=1024`, deterministic decoding (`do_sample=false`, temperature 0). Prompt sizes remained below the frozen 2048-token cutoff.

The 39 static fixtures cite the frozen verified result IDs; 38/39 B answers cited their receipt ID correctly. Fourteen B answers copied at least one receipt sentence of 20 or more characters. Copying alone was not counted as correctness: the manual full-pass review checked whether the answer addressed the request, matched expected material facts, and added no unsupported material claim. The nine backend receipts are reported separately and receive zero grounded-correctness credit. Their actual UUID result IDs differ from the frozen legacy IDs in all nine rows, so the original evaluator correctly treats references outside the frozen whitelist as unverified; no alias or hidden mapping was given to the model. Every one of the 48 receipts also has an `observed_at` later than its frozen `server_context.generated_at` (39/39 static receipts and 9/9 backend receipts). Thus the static subset has no result-ID-domain confound, but it still has an event-time confound: the authoritative receipts were observed after the frozen conversation context. The backend subset has both ID-domain and event-time confounds. Timestamps were not rewritten, and none of these differences were removed from the inputs. Interpret observed metric changes with these limitations.

The preregistered positive gate required gains across at least two static states and distinct fact shapes, at least four more static rows improving than regressing, no new material safety issue, and no state-level regression of 50 points or more. The gains meet the first conditions; `p0b038` violates the state-regression gate. The negative gate did not trigger because there was no new dangerous write/bypass or net factual/business deterioration. Therefore the registered outcome is `EXPERIMENT_B_GROUNDING_SIGNAL_WEAK`, despite clear gains in several static policy states.
